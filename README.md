# LAN Connect • TAMBOV

Offline LAN messaging project for Windows and Android 8.0+.
Development is ongoing; installers and hardware compatibility are not yet verified.

Requirements and actual test evidence: [VERIFIED_STATUS_RU.md](VERIFIED_STATUS_RU.md).
Build workflow and limits: [BUILD_RU.md](BUILD_RU.md).
User/source instructions: [README_RU.txt](README_RU.txt).

The GitHub workflow builds Windows EXEs and an Android APK, checks the packaged
server/Windows GUI dependencies, and verifies APK signature/manifest/DEX format.
A successful build is not a microphone, screen-sharing or real-device acceptance test.
No public release is published automatically.
