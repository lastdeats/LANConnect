# Android • LAN Connect / TAMBOV

Исходники нового нативного клиента Java. Android 8+ (API 26), целевой API 35.
Требуется проверка компиляции с Android SDK и работа на реальном устройстве.
Здесь нет собранного APK и нет утверждения о готовности.

В коде реализованы регистрация/вход, выбор людей и групп, переписка,
создание групп и приглашения, выбор файлов через системный диалог,
передача частями до 5 ГиБ с SHA-256 и восстановлением отправки,
скачивание без загрузки всего файла в память и сверка SHA-256 новых файлов.
Кнопка «История» открывает постраничную переписку, включая старые файлы. Пароль и токен не сохраняются.
Для продолжения прерванной отправки после повторного входа нужно выбрать
тот же файл и чат. Если поставщик не сообщает размер, клиент считает его потоком с пределом 5 ГиБ,
затем повторно открывает источник для отправки. Источник должен поддерживать
повторное открытие; файл целиком в RAM или кеш не копируется.
Скачивание пока повторяется с начала; неполный файл может остаться у пользователя.

Добавлены исходники аудиосвязи и просмотра/управления экраном Windows.
Микрофон включается только после согласия сторон и системного разрешения.
Сворачивание приложения завершает активный аудио/экранный сеанс.
Фоновая работа звонков, уведомления о вызовах при закрытом приложении,
передача собственного экрана Android и управление самим Android не реализованы.
Видеокамера не используется. HTTPS используется после настройки локального CA (см. ../TLS_RU.md).
HTTP оставлен для локальных тестов.

Сборка без Gradle, если инструменты уже установлены:

```
python build_android.py --sdk <путь-к-Android-SDK>
```

Нужны JDK 17+ (java, keytool, javac либо модуль jdk.compiler), SDK Platform 35
и Android Build Tools 35.0.0. Скрипт не скачивает зависимости.
Создаёт подписанный ключом разработки build/LANConnect-dev.apk и проверяет
подпись apksigner. Ключ по умолчанию хранится в ~/.lanconnect/dev-signing.jks.
Он нужен для последующих обновлений APK. Сборка не заменяет тестирование.

Приёмочные проверки: вход с Android, переписка с Windows и группой,
файл 5 ГиБ, прерывание и повтор отправки, запрет чужого скачивания,
аудио в обе стороны, отказ в разрешении микрофона, сворачивание/возврат,
экран ПК, щелчки с правильным масштабированием, немедленный отзыв доступа,
смена ориентации, потеря Wi-Fi, автономная работа в трёх подсетях.


Совместимость разных телефонов: COMPATIBILITY_RU.md. В код добавлены
запасные аудиорежимы 16/48/44,1 кГц с общим сетевым форматом,
обработка audio focus и ошибок выбора файлов. Кнопка ⓘ показывает сведения
об устройстве. Основной список ограничен 100 сообщениями/100 файлами,
старые записи — через историю. Подтверждений работы на Samsung/Redmi и
других реальных телефонах пока нет.

Общий Java-код проверяется исполнением `python test_compatibility.py`.
Синтаксис всех исходников: `java CheckJavaSyntax.java src`.
Это отдельные проверки; они не заменяют компиляцию Android APK.


Упаковка и постоянная подпись обновлены: см. ../BUILD_RU.md.
Режим --signing release требует существующий keystore, alias и пароль
через переменные окружения; новый dev-ключ в этом режиме не создаётся.
При успешной настоящей сборке проверяются apksigner, manifest и DEX,
а JSON-отчёт всё равно содержит device_tests_complete=false.
В текущей среде реальные SDK-инструменты не запускались.
