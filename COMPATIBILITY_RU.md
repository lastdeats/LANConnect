# Android-совместимость LAN Connect

Цель: Android 8.0+ (минимальный API 26), разные марки и размеры экранов.
Настройка minSdk сама по себе не подтверждает совместимость.
**APK не собран; испытаний на реальных телефонах пока нет.**

## Что изменено в исходниках

| Область | Реализация |
|---|---|
| Разные микрофоны | Сначала 16 кГц, затем 48 и 44,1 кГц; источники VOICE_COMMUNICATION и MIC. Неудачные кандидаты освобождаются. При отказе разрешения повторного обхода защиты нет |
| Общий формат звонка | В сеть идёт прежний PCM16 mono 16 кГц. Добавлен потоковый пересчёт частоты с фильтром перед понижением. Фаза сохраняется между порциями |
| Разные динамики | Пробуются 16/48/44,1 кГц; входящий звук преобразуется к выбранному режиму |
| Звук занят другой программой | Запрашивается системный audio focus; при потере фокуса сеанс закрывается. Приложение не отключает системное заглушение микрофона |
| Поздние ответы/жизненный цикл | Стоп отменяет ожидающие запросы и не даёт позднему ответу снова запустить сеанс; возврат из диалога разрешений учитывает состояние Activity |
| Разрешения | Отказ микрофона обрабатывается, при постоянном отказе предлагается открыть настройки приложения. Телефон без микрофона может использовать чаты и файлы |
| Выбор файлов | OPEN_DOCUMENT, запасной GET_CONTENT, запрос локальных файлов. Нет разрешения на доступ ко всем файлам телефона |
| Разные поставщики файлов | Колонки имени/размера ищутся по именам; при отсутствии размера пробуется дескриптор, затем ограниченный потоковый подсчёт. Файл не копируется целиком в RAM/кеш |
| Ограничение размера | 5 ГиБ, счётчики long. Источник с неизвестным размером читается дважды: для подсчёта, затем отправки. Он должен допускать повторное открытие |
| Память | Основное Android-состояние запрашивает до 100 сообщений/100 файлов. Старая переписка остаётся доступной через постраничную историю |
| Кадры экрана | Перед декодированием выбирается уменьшение до стороны не более 1280 пикселей; RGB565. Слишком большие размеры отклоняются; нехватка памяти закрывает просмотр |
| Небольшие дисплеи | Кнопки основных действий распределены по ширине; остановка сеанса вынесена в отдельную строку. Визуальная проверка и большие системные шрифты ещё нужны |
| Диагностика | Кнопка ⓘ показывает модель, Android/API, ABI, размер окна и статус микрофона. Копирование — по кнопке пользователя |

Приложение использует Java/Android SDK, без Google Play Services, Firebase,
Samsung/Xiaomi SDK и ABI-зависимых библиотек .so. Планируется общий APK для
32- и 64-битных Android-устройств. Это не результат испытаний обеих архитектур.
Huawei рассматривается только с системой, поддерживающей Android APK;
отдельная нативная версия HarmonyOS NEXT не разрабатывалась.

## Что проверено на этом этапе

`python android/test_compatibility.py` компилирует общий код в байткод Java 8
и **исполняет** тесты на JDK 21. Android SDK в этой проверке не участвует.
Проверены:

- 16 ↔ 44,1/48 кГц, точное число отсчётов и совпадение при разном разбиении на порции;
- передача знака/порядка байтов PCM, предельные значения, подавление высокочастотного алиасинга;
- выбор запасного аудиорежима, немедленное прекращение попыток при запрете доступа;
- подсчёт файла короткими чтениями, пустой файл, остановка, зависший источник с нулевым чтением;
- счётчик ровно 5 ГиБ и отказ на байт больше на **виртуальном потоке без записи 5 ГиБ**;
- отмена запоздалых ответов после остановки и защита нового разрешения от старого опроса;
- расчёт уменьшения кадров для ограниченного потребления памяти.

Android-зависимые файлы отдельно проверены на синтаксис. Они не компилировались
против android.jar. Ни AudioRecord/AudioTrack, ни файловые диалоги, ни UI этим
JVM-тестом не запускались. Реальная проверка 5 ГиБ через сервер описана отдельно
в VERIFIED_STATUS_RU.md; её нельзя считать тестом телефона.

## План приёмки по семействам — пока не выполнен

| Семейство | Что дополнительно проверить | Результат |
|---|---|---|
| Samsung | Микрофон/наушники, «Мои файлы», крупный шрифт, маленький экран | Не проверено |
| Redmi / Xiaomi / POCO | Микрофон, системный файловый диалог, возврат из настроек, потеря Wi-Fi | Не проверено |
| realme / OPPO / vivo | Звук, выбор файла, отзыв разрешений, прерывание отправки | Не проверено |
| Honor / Huawei с Android APK | Работа без Google, локальные файлы, сертификат локального CA | Не проверено |
| Pixel, включая Android 17 | Фокус звука, системные разрешения, TLS, поворот/системные панели | Не проверено |
| Старое 32-битное устройство Android 8–10 | Запуск, память, пересчёт звука, крупные файлы и счётчики | Не проверено |

На каждой платформе нужны чаты Windows ↔ Android, аудио в обе стороны,
согласие/отказ, остановка, файл до 5 ГиБ, три маршрутизируемые подсети и
работа с отключённым Интернетом. Самыми важными остаются крайние версии
Android и хотя бы по одному доступному Samsung и Redmi.

Звонки по-прежнему только при открытом приложении: при сворачивании/потере
связи сеанс останавливается. Фоновые звонки, push и передача собственного
экрана Android здесь не реализованы. Уменьшение изображения не заменяет
измерения реального расхода памяти и тестов клавиатуры/поворота/масштаба.

## Команды

```
python run_tests.py --tls --android-core
java android/CheckJavaSyntax.java android/src
python android/build_android.py --sdk <Android-SDK>
```

Для сборки нужны SDK Platform 35, Build Tools 35.0.0 и JDK 17+.
Сценарий компиляции Android использует android.jar как boot classpath и
Java 8 bytecode target. SDK по-прежнему отсутствует в доступной среде.

Справочные API: [AudioRecord](https://developer.android.com/reference/android/media/AudioRecord),
[audio focus](https://developer.android.com/media/optimize/audio-focus),
[Huawei: переход APK-приложений к HarmonyOS NEXT](https://developer.huawei.com/consumer/en/doc/HarmonyOS-Guides/app-data-migration-overview/).
