LAN Connect • TAMBOV — разработка продолжается, это исходники, не готовый выпуск
Актуальная проверка: 19.11.2026. Подробности — VERIFIED_STATUS_RU.md.

Запуск сервера из исходников: python server.py
Запуск Windows-клиента из исходников: python client.py
Проверки: python run_tests.py
Проверки с HTTPS (нужен cryptography): python run_tests.py --tls
Реальные 5 ГиБ: python test_large_file.py --run --temp-root <диск-с-7ГиБ-свободного-места>
Сборка Windows на Windows с Python 3.12: build_windows.bat
Исходники Android и скрипт сборки: android/README_RU.md

Сборочный скрипт Windows устанавливает PyInstaller и Pillow из
requirements-windows.txt. Для первоначальной подготовки инструментов
может понадобиться Интернет. EXE и APK здесь не собраны.

Клиентам во всех трёх маршрутизируемых подсетях нужен один доступный IP
сервера: https://<IP-сервера>:8080 после настройки TLS (см. TLS_RU.md).
Для локальных тестов без TLS — http://<IP-сервера>:8080.
127.0.0.1 подходит только на самом сервере. Автообнаружения нет.
Разрешить на сервере входящий TCP 8080 из 20.20.136.0/24,
20.20.137.0/24 и 20.20.138.0/24, проверить маршруты между подсетями.
Реальные правила Windows Firewall и маршрутизаторов здесь не менялись.
Все чаты, файлы, звук и экран идут через выбранный сервер, без облака.

Сервер: LAN_HOST=0.0.0.0, LAN_PORT=8080 по умолчанию.
LAN_DATA_DIR — необязательный абсолютный путь к папке данных.
По умолчанию server_data рядом с server.py/EXE, папка должна быть доступна
для записи пользователю сервера.
LAN_STORAGE_GIB=200 — квота файлов, LAN_MIN_FREE_GIB=30 — резерв диска.
Размеры задаются в двоичных ГиБ. Один файл — не более 5 ГиБ.
Счётчик квоты включает завершённые файлы и зарезервированные загрузки.
Файлы удаляются через 10 дней после завершения загрузки, проверка раз в 5 минут.
Незавершённые загрузки удаляются через сутки без обновления.
После выключения сервера очистка выполняется при следующем запуске.
Метаданные сохраняются. Лимит 200 ГиБ относится к файлам, а не к БД.

Новые сеансы /live/: аудио PCM16/16кГц, JPEG-экран, отдельные права
просмотра/управления и явное согласие. Подробнее — README_REMOTE.txt.
Ограничены 128 сетевых обработчиков и 16 одновременных live-сеансов.
В коде Windows добавлены микрофон/динамики, захват основного экрана,
кнопка остановки и ограниченные действия мыши/клавиатуры.
Их аппаратная работа на Windows пока не проверена.

Android написан с нуля: есть исходники чатов, файлов, аудио и просмотра/
управления экраном ПК. Собственный экран Android не передаётся.
Звонки только при открытом Android-приложении; при сворачивании завершаются.
Видеозвонки и работа камеры не добавлялись.

История: кнопка «История» в Android и «История выбранного чата» в Windows.
Окно читает страницы с сервера, не загружая всю переписку в память.
Старые файлы можно скачать по их ID в Windows или кнопкой в Android.
Срок 10 дней продолжает действовать: просроченные байты не возвращаются.

У новых серверных файлов сохраняется SHA-256. Клиенты проверяют его
при скачивании (Windows — перед заменой итогового файла).
Старые записи без хеша сохраняют совместимость, но проверяются только по размеру.
Тесты этого этапа: test_history.py, test_integrity.py и расширенный test_smoke.py.

Android-совместимость: android/COMPATIBILITY_RU.md.
Добавлены запасные режимы звука, обработка разных файловых провайдеров,
ограничения памяти и сведения об устройстве. Эти изменения не означают,
что APK уже проверен на телефонах. Для общего Java-кода:
python run_tests.py --tls --android-core
Нужен JDK с компилятором. Полная сборка APK по-прежнему требует Android SDK.

Сборки EXE/APK и GitHub Actions: BUILD_RU.md.
Новый build_windows.py проверяет готовые EXE; отдельно планируется
LANConnect-TLS.exe для настройки сертификатов без Python.
В среде разработки проверена исходная серверная проба, но не EXE.
Подключение GitHub выполнено; доступный репозиторий ещё не выбран/не найден.
